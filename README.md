# GymOS — Block 8 (web app v0.8)

Personal training app: Block 8 "Rebuild & Burn" (10 Aug – 20 Sep 2026).

## Hosting on GitHub Pages (one-time, ~10 minutes)
1. Create a repository named `gymos` (public).
2. Upload all files in this folder to the repository root (drag & drop works on github.com).
3. Repository → Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
4. After ~1 minute your app is live at `https://<your-username>.github.io/gymos/`.
5. On your phone: open that URL in Chrome → menu → **Add to Home screen** (installs as a real app: icon, fullscreen, offline).

Hosted = technique videos play inside the app; offline logging still works (service worker).
Your existing data: open the old local file → More → Export, then open the hosted app → More → Import.
